# Parrucchiere Oscar - sito statico

Pubblicazione su GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).

- `index.html`, `style.css`, `script.js`: nessuna build, nessuna dipendenza (solo Google Fonts, gratuito).
- `assets/`: immagini, vedi `assets/LEGGIMI.txt` per i nomi dei file.
- `script.js` (inizio file): oggetto `CONFIG` per telefono, WhatsApp, email, indirizzo, mappa, orari, social.
  Finche' e' vuoto, i contatti non compaiono e il modulo di prenotazione avvisa che non e' ancora attivo.
- Nessun prezzo, recensione o dato di contatto e' stato inserito: vanno forniti dal titolare.
- I servizi in `index.html` sono generici e vanno confermati/modificati dal salone.
